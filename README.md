# Indian Vehicle Simulator 3D — Open World

Original browser-based 3D open-world prototype inspired by the *style* of Indian vehicle simulator games.

## Included in this build

- Large procedural 3D Indian-style city
- Island world surrounded by sea
- Roads, buildings, trees and traffic
- 3D player character and multiple animated NPC pedestrians
- Cars, bikes, buses, trucks and tractors
- Airport outside the main city
- Runway, terminal and helipad
- Airplane and helicopter
- Airport bridge/road connection
- Harbour/dock area
- Day/night mode
- Clear, rain and fog weather modes
- Third-person vehicle/character movement
- Vehicle enter/exit state
- Responsive HUD

## Controls

- **WASD / Arrow keys:** move
- **E:** enter/exit vehicle
- **R:** reset player vehicle
- **N:** day/night
- **T:** weather

## Next expansion targets

The project is structured so more original 3D vehicle models, NPC types, missions, interiors, traffic AI, airport operations, boats and a larger detailed city can be added without replacing the world.

> Note: this project uses original procedural geometry and does not copy proprietary game assets or source code.
